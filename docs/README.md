# Skill Similarity Engine Documentation

This directory contains documentation for the Skill Similarity Engine in both Markdown and HTML formats.

## Why Two Formats?

The documentation is available in two formats for different use cases:

### Markdown Files
- **Purpose**: Integration with GitHub/GitLab, easy editing and tracking in version control
- **Limitations**: Mermaid flowcharts may not render properly in all Markdown viewers

### HTML Files
- **Purpose**: Guaranteed rendering of interactive Mermaid flowcharts, better reading experience
- **Benefits**: Consistent formatting, interactive diagrams, better styling

## Using the HTML Documentation

For the best experience viewing the flowcharts and diagrams:
1. Open `index.html` in a web browser
2. Navigate to the specific document you want to view
3. All Mermaid diagrams will render automatically

## Updating Documentation

When updating content, please make changes to the Markdown files first, then regenerate the HTML versions to ensure consistency between formats.

## Notes on Mermaid Flowcharts

The Mermaid flowcharts in these documents visualize important concepts like:
- System architecture
- Data processing flows
- Algorithm steps
- Enhancement factor calculations

While these may appear as text in some Markdown viewers, the HTML versions will always render them correctly as interactive diagrams.

Getting Started

The Skill Similarity Engine is a command-line tool for analyzing job roles based on their skill requirements. It helps identify similar roles, calculate skill gaps, and generate career pathways.

Prerequisites

  • Python 3.8 or higher
  • Pip (Python package manager)
  • Minimum 8GB RAM recommended
  • Basic familiarity with command-line operations

Quick Start

For users already familiar with Python applications, here's a quick way to get started:

# Clone the repository
git clone https://github.com/yourusername/skill-similarity-engine.git
cd skill-similarity-engine

# Install dependencies
pip install -r requirements.txt

# Generate a configuration file
python -m scripts.skillsim.py config generate --output-path my_config.yaml

# Run a basic similarity analysis
python -m scripts.skillsim.py run similarity --config-file my_config.yaml --output-dir ./output
